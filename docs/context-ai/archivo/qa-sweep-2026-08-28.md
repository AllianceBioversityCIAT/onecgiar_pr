## Verified healthy — do not re-test from zero

**Bilateral creation wizard.** Project search including the empty state; Outcome and Output each
offering the right result types; Contributing SPs and Bulk upload correctly marked *Coming soon*.

**Theory of Change, all combinations.** "No" → justification appears and saves; switching "No"→"Yes"
clears the justification in the database with no orphan; "Yes" → Level → ToC result → indicator →
target → contribution → narrative, all persisting across reloads; changing the Level clears the
dependent fields both on screen and in the database (only the narrative fails — P2-3525);
contribution respects min and step (`-5`→0, `3.7`→4).

**Geographic Location, all five scopes.** Global and "Yet to be determined" hide the rest; Country
and Sub-national reveal and save (Mali + Bamako + Ségou persisted); switching back to Global
**clears the countries in the database** — no orphans.

**Evidence.** Rejects a non-URL (button disabled) and enforces the 6-item cap (the add button
disappears at the seventh).

**Type-specific sections.** Capacity Sharing, Innovation Development, Innovation Use, Policy Change
and Knowledge Product all render and persist. Other Output and Other Outcome correctly have none —
and the "Type-Specific 0/0" row the sidebar shows for them is cosmetic: a 0/0 section adds nothing
to either side of the percentage, so the result still reaches 100% and Submit unlocks (verified).

**Knowledge Product sync.** Five real CGSpace handles resolved to their correct titles; the result
is created pre-filled from the repository (title, description, geography, evidence — 69% on
creation).

**W1/W2 reporting end to end.** All five sections turn green on save and the result submits.
Impact Area score buttons work (P2-3477 holds in this branch).

**Reviewer cycle end to end.** Submit → appears in the programme queue → drawer opens with the
result → REJECT requires a justification (Confirm disabled without text) → status flips to Rejected
→ **the centre sees the justification with author and date** in its own list. P2-3157 works.

**Filters.** Search (213→2, correct empty state, URL kept in sync), status filter (213→171, every
visible row matching), status + centre combined (4 rows, both conditions), and Clear Filters
restoring all 213. No leakage between filters.

## Environment notes

- `prtest-back` returned intermittent 503s all day (2 failures in 24 probes over 4 minutes). Any
  "Save failed" seen during testing must be checked against the backend before being called a bug —
  one was, and it was not.
- Do not run prettier in this checkout: it reformats whole files against the current config and will
  overwrite other agents' work. `ng lint` passes without it.
- A dev server that is running when `node_modules` changes keeps the old compiler in memory and
  reports errors that do not exist. Restart it after any dependency update.
