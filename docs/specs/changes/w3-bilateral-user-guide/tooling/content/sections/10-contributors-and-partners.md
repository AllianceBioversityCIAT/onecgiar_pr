**Contributors & partners** records who else is behind this result. The **Primary contributing
science program** and **Lead center** are shown read-only, assigned automatically from the
project's own mapping — you cannot change them from here. Below them, three optional pickers let
you add more contributors: **Contributing science programs**, listing every Science Program other
than the primary one — not only the ones already mapped to the project, unlike the Contributing
Science Programs step in the setup drawer; **Contributing CGIAR centers**; and **Contributing
W3/bilateral projects**, which lists every other bilateral project you can link this result to.

The one required control in this section is **External partners**: either check **This result has
no external partners**, or select at least one partner from the picker that appears when that box
is unchecked — the section needs one or the other to be complete.
