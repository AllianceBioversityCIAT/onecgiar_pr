Clicking **Overview** in the section rail — it is not where the editor opens, so you have to click
it — opens a dashboard that summarizes the W3/Bilateral project this result is linked to, next to
the result's own identity: its code, type, and reporting phase, and its funding source. The
project's Lead Center, its summary, and its description are all shown read-only here.

While the result is still open to editing, two fields on this same dashboard are not read-only:
**Project** and **Program** — the Primary Science Program — can both be changed here, and a **Save
project and program** button appears once you have picked a different one, to persist the change.
This is the only place in the editor where the project and Primary Science Program can be changed;
the Contributors & partners section, covered later in this guide, shows the Primary Science Program
read-only.

To the left of every section sits the **section rail**, the column that lists the result's
sections in order and that you use to move between them. Above the list it carries a link back to
where you came from and the result's own identity — its code, its type, and a status badge; below
the list, and once this result already has an AI quality assessment on file, a short quality
summary appears there too — before the progress bar and its "N of M sections complete" label,
which in turn sits above the **Submit for review** button covered later in this guide.
