**Type-specific details** carries the fields that only apply to the result's own type — a badge at
the top of the section names that type, and the fields beneath it change with it: Policy Change,
Innovation Use, Capacity Sharing for Development, Knowledge Product, and Innovation Development
each show their own set of questions.

This section **does not appear at all** for an Other Outcome (type 4) or an Other Output (type 8)
result — not as an empty section, but missing from the rail entirely, because those two types have
no type-specific fields to collect. Every other result type keeps this as its sixth and last rail
section.
