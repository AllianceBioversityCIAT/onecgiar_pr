The **Reporting** tab opens onto the project catalog: the list of bilateral projects the Center
can report results against. A search box lets you look a project up by code, title, or program,
and a row of quick filter chips narrows the list to one Science Program at a time.

Above the catalog, a strip of KPI cards doubles as a filter: a **Total Projects** card, one card
per top Science Program, and — when the Center has projects mapped to more than one Program — a
**Multi-Program** card for co-mapped projects. Clicking any of these cards filters the catalog
below to match it; the **Total Projects** card, the **All** chip, or — when no projects match —
**Reset Filters** clears it. A view switcher lets you display the catalog as a grid of cards or
as a dense table; the table
trades the card view's "Active" status indicator for a more compact row.

Each **project card** carries the project's code, an "Active" status indicator, a badge showing
how many results have already been reported against it, the project's title and summary, and —
when the project contributes to more than one Science Program — a Science Program Alignment box
listing each Program with its percentage allocation. A single-Program project shows that one
Program at 100%. The card's footer offers two actions: **View results**, which opens the
project's already-reported results in the Results tab, and **Create result**, which opens the
setup drawer for a new result on that project — clicking anywhere else on the card does the same
thing as **Create result**. That drawer is covered next.
