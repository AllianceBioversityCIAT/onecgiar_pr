Clicking **Create result** on a project card — or the card itself — opens the **Set up bilateral
result** drawer on the right side of the screen, with the project's code and title shown at the
top so you always know which project you are reporting against.

If the project contributes to more than one Science Program, the drawer's first step asks you to
**select a Primary Science Program**: pick the one Program this result is primarily reported
against from a list of radio options, each showing the Program's code, name, and its allocation
percentage on the project. A project mapped to only one Science Program skips this step entirely
and treats that single Program as primary.

Once a primary Program is set, and if the project has other Science Programs mapped to it, an
optional **Contributing Science Programs** list appears below: a set of checkboxes for any
additional Programs or Accelerators that also contribute to this result. Selecting contributing
Programs is not required to continue — only the primary selection is.

With the Science Program step settled, the drawer moves to its next step: choosing how you want
to report the result, covered next.
