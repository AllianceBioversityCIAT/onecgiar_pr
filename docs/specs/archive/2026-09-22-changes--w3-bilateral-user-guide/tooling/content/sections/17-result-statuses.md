The result editor's identity strip, at the top of the section rail, carries a small status badge
next to the result's code and type. Only four values render there: **Editing** — while the result
is still open for you to work on; **Pending review** — once Submit for review, covered earlier in
this guide, has moved it out of your hands; **Approved**; and **Rejected**. A result in any
other state shows no badge at all in this identity strip — the header only recognizes these four.

These same four values are also everything a result you create and submit yourself, through the
manual path this guide documents, will ever carry. It starts in Editing, moves to Pending review
the moment Submit for review succeeds, and from there the Science Program's own review settles it
as either Approved or Rejected — it never passes through any other state along the way.

The **Results** tab, described earlier in this guide, lists every bilateral result recorded
against the Center — not only the ones a reporter created and submitted through this manual path
— and its Status filter and Status column carry three further values beyond the editor's four:
**In QA**, **Submitted**, and **Discontinued**. Those apply to results that reach the system
another way — for example, ones submitted through the platform's ingestion API rather than typed
by hand, or ones an administrator has discontinued — and you may see them while browsing that
list. A result you create and submit through the manual form and editor this guide describes does
not pass through any of the three.
