The Innovation Packages module lists every Innovation Packages and Scaling Readiness (IPSR)
assessment your Program can access, one row per package, with its submitter, status, phase
year, and phase portfolio. Use the **Find result**, **Submitter**, **Phase**, or **Package
status** filters to narrow the table. To start a new assessment from scratch, click **Create a
new Innovation Package**.

This page matters because it is where a Program tracks its innovations through the IPSR
pathway — from an early assessment to a package ready for scaling — separately from the
individual results listed in the Results Center. Each row's PDF icon gives you a shareable
copy, and **Download** exports the current table.

To review or continue work on a specific package, click its title in the table — for example,
the first package listed. That opens the full assessment, including where to add
scaling-readiness details or move it toward submission.
