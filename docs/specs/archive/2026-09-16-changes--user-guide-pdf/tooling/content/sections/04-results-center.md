The Results Center is a single searchable table of every result across all Programs and
Centers — results here cover the full range of Program work, including knowledge products,
innovation development, policy changes, and more. Use **Filter** and the phase tags (for
example **Phase: Reporting 2026 (Open)**) to narrow the table to one Program, Center, phase, or
status, and the search box to find a result by title, code, or indicator.

This page matters because it is the one place a P/A goes to update a result after it was first
created elsewhere — including this year's innovations. If your Program already has innovations
logged for the current reporting year and their status, contributors, or details need changing,
this is where you make that change: filter the table to the current phase and, if useful, the
**Innovation development** category to find the result, then click **Update result** in the
page header and pick the result you want to change.

You can also export the current table view with **Export CSV** for offline review.
