Bell — read state (Option A)

Interactive mockup for notifications/bell-read-state. Click a row to read it, press Mark as read, or simulate a new request arriving. The badge counts only what you have not read or seen yet. Requests needing a decision always stay in the list until someone accepts or declines them.

How it reads

● Bold + dotUnread / not seen yet: counts on the badge. LightRead / seen: stays in the list, does not count. Requires decisionStill needs Accept / Decline, read or not. Counted in the Decide tab until decided.

Rules

  • Badge = unread updates + requests not seen yet.
  • Opening the bell changes nothing (as today).
  • Clicking a row opens it and marks it read: it turns light in place, the badge drops by 1.
  • Mark as read: every row turns light, the badge goes to 0. Requests stay in Decide with their buttons.
  • Decide tab always shows how many requests are waiting for a decision, read or not.
  • Accept / Decline removes the request from everywhere.
  • Same state on every device, and the same in the inbox page.
