## 1. Conventions

- **Columns:** `key` (proposed, dotted `section.name`, snake_case) · `label` (exact UI text; `—` = control has none) · `type` · `sec.ord` (section key + order inside it) · `list` (control-list key, see §3) · `storage` (`col:` = column binding; `rel:` = table + fk_to_result + value_column [+ filter]) · `req` (`yes` / `no` / `cond` / `no live rule …`) · `required_when` · `conf?` (`yes` only when a **supplied live** function states the rule; the function line is in `origin`) · `origin` (`client file:line` of the control ‖ `V-xx:line` of the rule).
- Subfields are nested rows (`↳`). Read-only/display rows are included (they are form content) and flagged `RO`.
- Result type keys (from `definitions/result-types.ts`): `knowledge_product`, `capacity_sharing`, `innovation_development`, `other_output`; `*` = every type.
- Section keys proposed: `general_information` (10) · `toc_alignment` (20) · `contributors_partners` (30) · `geographic_location` (40) · `<type page>` (50) · `evidence` (60) · `linked_results` (70). *(Client order is GI, C&P(+ToC+linked), Geo, type page, Evidence; the `sec.ord` numbers are the catalog order, not the client order.)* `toc_alignment` and `linked_results` are blocks inside the client C&P page; they are split here because the brief asks for them separately.
- Path shorthand (client root `onecgiar-pr-client/src/app/`): **RD** = `pages/results/pages/result-detail/pages`; **GI** = `RD/rd-general-information/rd-general-information.component`; **CP** = `RD/rd-contributors-and-partners/rd-contributors-and-partners.component`; **MWC** = `RD/rd-contributors-and-partners/components/multiple-wps/components/multiple-wps-content/multiple-wps-content.component`; **NS** = `…/multiple-wps/components/normal-selector/normal-selector.component`; **KPS** = `…/multiple-wps/components/knowledge-product-selector/knowledge-product-selector.component`; **GEO** = `RD/rd-geographic-location/rd-geographic-location.component`; **GM** = `shared/components/geoscope-management/geoscope-management.component`; **EV** = `RD/rd-evidences/rd-evidences.component`; **EI** = `RD/rd-evidences/evidence-item/evidence-item.component`; **AU** = `shared/components/annual-updating/rd-annual-updating.component`; **FM** = `shared/services/fields-manager.service.ts`; **API** = `shared/services/api/results-api.service.ts`; **KPI** = `RD/rd-result-types-pages/knowledge-product-info/knowledge-product-info.component`; **CDI** = `RD/rd-result-types-pages/cap-dev-info/cap-dev-info.component`; **IDI** = `RD/rd-result-types-pages/innovation-dev-info/innovation-dev-info.component`.
